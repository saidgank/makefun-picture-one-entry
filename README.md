One picture of food that tastes of one ingredient: a single perfect ripe strawberry, macro-photographed, glossy with dew, filling the frame against a dark background. Nothing else is in the picture — one ingredient, one picture. Running `main.py` copies `entry.jpg` to the output directory as `entry.png` on every run.

## Run it

```bash
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png`, a copy of the strawberry photograph.
