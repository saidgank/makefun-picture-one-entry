One picture of food that tastes of one ingredient: a single perfect ripe strawberry, macro-photographed, glossy with dew, filling the frame against a dark background. The entry is `entry.jpg`, and `main.py` copies it to the output directory as `entry.png` every time it runs.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
