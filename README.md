One picture of food that tastes of one ingredient: a single perfect ripe strawberry, macro-photographed — deep glossy red, plump and fresh, dew catching the light, one green leaf still attached — filling the whole square frame against a dark background. One look and you can taste it. main.py copies entry.jpg to the output directory, byte for byte, every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py  # writes out/entry.png
```
