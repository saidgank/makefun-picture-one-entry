One picture of food that tastes of one ingredient: a single perfect ripe strawberry, macro-photographed, glossy with dew, filling the frame against a dark background. The picture is embedded in `main.py` as base64, and `main.py` writes it to the output directory every run — no binary image file is stored in this repo.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png`, a 1024x1024 picture of the strawberry.
