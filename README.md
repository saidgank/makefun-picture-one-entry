One picture of food that tastes of one ingredient: a single perfect ripe strawberry, macro-photographed, glossy with dew, filling the frame against a dark background. No other ingredient, no plate, no hands — just the one strawberry. `main.py` copies `entry.jpg` to the output directory as `entry.png` on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
